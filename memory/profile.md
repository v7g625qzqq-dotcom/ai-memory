# User Memory Profile
> Last updated: 2026-10-04T02:44:55+08:00
> Version: 6

## Memory Block

**工作背景**
用户是淘宝/电商卖家与视觉设计从业者，当前在制作一款鸡用喂食器（"喂鸡神器"）的主图素材，同步运营速卖通（AliExpress）跨境店铺与店匠（Shoplazza）独立站（chinmiss.myshoplazza.com，205 款打火机商品）。日常使用千牛、拼多多工作台、微信小店助手等多平台运营工具，通过店小秘 ERP 统一管理速卖通店铺（包括【个体户】打火机店铺，约 90 款商品，视频源来自店小秘关联的速卖通打火机店铺）。常驻向日葵、ToDesk、GameViewer 等远程控制软件。Windows 工作环境，视频搬运与上架流程依赖 cdp-driver 架构（Playwright-core Chrome + cmd.json/result.json 文件队列）实现浏览器自动化。

**个人背景**
中文沟通，期待诊断/操作方案以"优先级列表 + 表格 + 解释说明"的结构化形式呈现，直接给出状态更新与简洁摘要。涉及卸载、清理等破坏性系统操作时，习惯先由 AI 列出待执行动作并获得确认后再执行，避免误操作。偏好 AI 直接执行浏览器自动化任务而非提供手动指引；下达简短跟进指令时，期望 AI 自主推进下一步，无需反复确认；方案确定后倾向授权 AI 全权执行（"就按你想的来"）。

**当前关注**
聚焦多线任务并行：(1) 淘宝喂鸡神器主图设计；(2) 店匠独立站商品视频与装修——已将 80/205 款打火机商品的视频从速卖通经店小秘 ERP 完成搬运，仍剩 125 款待批量补齐主图视频，并基于已上传商品推进首页装修/陈列（首页正在围绕 煤油打火机 / 丁烷打火机 / 电弧打火机 三大分类进行搭建）；(3) 速卖通店铺使用华翰物流（线下专线自寄）发货，需配置运费模板使买家承担实际物流成本。同时硬件资源受限：Intel i5-11400（6 核）+ 32GB 内存，仅 Intel UHD 730 核显（无独显）；桌面端使用 Qualcomm QCA9377 Wi-Fi（1x1、433Mbps）而非有线网络；C 盘 NVMe 系统盘仅剩约 29.8GB（13%），对设计软件运行与视频/素材存储构成持续压力。

**近期动态**
- 为喂鸡神器商品启动淘宝主图设计工作。
- 店匠独立站商品视频搬运进展：速卖通【个体户】打火机店铺（约 90 款商品）经店小秘 ERP 获取视频，已完成 80/205 款，仍剩 125 款待批量补齐主图视频。
- 在视频补齐基础上，启动店匠店铺装修/陈列工作，基于已上传商品进行整体页面优化；首页按 煤油打火机 / 丁烷打火机 / 电弧打火机 三大分类搭建。
- 速卖通店铺采用华翰物流（线下专线自寄）作为发货方案，目标配置运费模板使买家承担实际物流成本。
- 同时运营店匠（Shoplazza）独立站（chinmiss.myshoplazza.com，205 款打火机）与速卖通店铺，店小秘 ERP 作为跨平台商品/库存管理中枢。
- 浏览器自动化采用 cdp-driver 架构（Playwright-core Chrome + cmd.json/result.json 文件队列），由 AI 端到端执行而非提供手动指引。
- C 盘系统盘空间告急（剩余约 13%），可能影响 PS/AI 等设计软件运行与素材存储；视频搬运任务将进一步加剧磁盘压力。
- 电脑常驻多款远程控制与电商工作台软件，后台资源占用需关注；Wi-Fi 替代有线网络可能影响大文件（视频素材）传输效率。
