### ⚠️⚠️ 最隐蔽的坑：bat 文件必须是 GBK 编码（已修）

```

'indirect' 不是内部或外部命令    ← "swiftshader_indirect" 被拆
```

**根因**：中文 Windows 系统代码页是 **936 (GBK)**，而 Write 工具产出的是

```python
import io
s = io.open(f, encoding='utf-8').read()

```
