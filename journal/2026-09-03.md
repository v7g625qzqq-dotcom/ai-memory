## 排查有线网络（网线闪黄灯连不上网）

**症状**：电脑插网线连不上网，网口闪黄灯。

**诊断结果与处理**：
- 根因一：有线网卡（Realtek PCIe GbE，"以太网"）在系统里被禁用。已用 `netsh interface set interface "以太网" admin=ENABLED` 启用。
- 根因二：网卡原配静态 IP 192.168.1.200（DHCP 关闭），走外网被网关回"目标网络不可达"。已改为 DHCP 自动获取。
- 根因三（待用户处理）：链路只协商到 100Mbps（黄灯）且不稳（闪黄灯），DHCP 拿不到 IP（回落 169.254 APIPA）。判断为网线/接口物理问题，需用户换线、换口、插紧。

**硬件网络信息**：
- 有线网卡 MAC：B0-7B-25-20-1C-4F，Realtek PCIe GbE Family Controller（千兆）
- 无线网卡：Qualcomm QCA9377，DHCP 192.168.1.193
- 网关/路由器：192.168.1.1
- 主机名：1B1V

**环境备注**：本机 PowerShell 工具 stdout 捕获异常（返回 exit 0 但无输出），诊断一律改用 Bash 调用 netsh/ipconfig 等原生命令；grep 中文需加 `-a`（输出为 GBK，被视为二进制）。
