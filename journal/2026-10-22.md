### 关键技术突破（可复用）

**1. Cookie 解密（两边都是 AES-256-GCM，不是 CBC）**
- 格式：`v10` + 12B nonce + ciphertext + 16B tag
- 密钥：Local State / LocalPrefs.json → `os_crypt.encrypted_key` → DPAPI 解密 → 32B
- 千牛：`C:\Users\DELL\AppData\Local\QNCEF1301Temp\instance_*/<店铺profile>/Network/Cookies`
  + 密钥在同 instance 根的 `Local State`
- PDD：`C:\Users\Public\Documents\PDD\PddBrowser104\User Data\<cs_md5>\Network\Cookies`
  + 密钥在 `User Data\Local State`
- 解密后明文可能带 32 字节 SHA256(host_key) 前缀，需剥离
- 之前误判为 CBC 是走弯路的关键教训

**2. 淘宝 MTop API 自研客户端**（`extract/mtop_client.py`）
- 签名：`sign = md5(token & t & appKey & data)`，token = `_m_h5_tk` 的 `_` 前半段
- **坑1**：`_m_h5_tk` 与 `_m_h5_tk_enc` 必须成对发送，缺一报 `FAIL_SYS_TOKEN_EMPTY`
- **坑2**：服务端每次下发新 token 对，旧值立即失效 → 每次响应后必须立即吸收 Set-Cookie
- **坑3**：服务端下发的 cookie domain 是 `taobao.com`（host-only），需复制到 `.taobao.com` 才能发给 `h5api.m.taobao.com`
- **坑4**：必须带 `callback=mtopjsonpN` 参数
- **坑5**：国内站点要 `session.trust_env = False`，否则走系统代理会 502
- 参数错误时返回 `FAIL_SYS_BIZPARAM_MISSED::缺少业务参数xxx` —— 可用来反推参数名
- 接口不存在时返回 `FAIL_SYS_API_NOT_FOUNDED` —— 可用来做批量接口探测

**3. 千牛商品数据走 DOM 提取（不是 JSON API）**
- 路由：`https://myseller.taobao.com/home.htm/SellManage/<tab>?current=1&pageSize=50`

- **必须先点工作台「商品」菜单建立 micro-app 上下文**，直接 goto URL 拿不到表格
- DOM 结构：`tbody.next-table-body > tr.next-table-row`，`td[label="商品名称"]` 里
  `a.title-link` 是标题（href 含 `id=<itemId>`），文本含 `ID:<数字>`
- **table 元素本身没有 `next-table` class**，只有 tbody/tr 有
