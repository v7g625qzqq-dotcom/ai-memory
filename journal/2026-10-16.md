# 2026-10-16

## Tinkercad Lite 本地三维设计软件

在 `tinkercad-lite/` 从零实现了一个纯前端三维建模软件（对标 Tinkercad 的建模部分，不含社区/教学）。

- 技术栈：Three.js + three-bvh-csg（BVH 加速布尔）+ Vite + 原生 JS，无框架无后端。
- 功能：8 种基本体（含圆角长方体）、三轴变换手柄 + 10mm 吸附、并集/差集/交集、编组、九向对齐、撤销重做（快照式，60 步）、STL/OBJ 导入导出、JSON 工程存取 + localStorage 自动暂存。
- 单位约定：1 three 单位 = 1mm。
- 验证方式：`npm run build` 通过 + Playwright 真实浏览器跑通「加形状 → Shift 多选 → 布尔运算 → 属性面板」，零 console/page error。
- 运行：`npm run dev`（开发）或 `npm run build` 后用 `dist/`（可纯静态分发）。

踩坑记录：
1. `ExtrudeGeometry` 的 `absarc` 参数写成 `Math.PI.PI`（undefined）会静默产生破面，必须是 `Math.PI`。
2. 圆角半径需 `Math.min(r, w/2, h/2)` 夹紧，否则半径过大时截面退化成自相交路径。
3. 编辑 `if/else if` 链时插入 `else { ... }` 容易造成语法错乱，改完务必跑一次 build 兜底。

## 追加：离线化（file:// 双击可用）

林老板问断网能不能用 + 能否做到和 Tinkercad 一样。离线部分已彻底解决，实测通过。

- `vite.config.js`：`base: './'` + `format: 'iife'`。
- `inline.mjs`：构建后把 JS/CSS 全部内联进 index.html，产出**单文件** `dist/index.html`（约 1.3MB）。
- 离线验证：Playwright 用 `file://` 打开 + route 拦截阻断一切非 file/data/blob 请求，跑通「加体→多选→布尔→加体」，外部请求 0 个、零报错。

**关键坑（务必记住）**：
1. Chrome 对 `file://` 下的**外链** JS/CSS 一律按 CORS 拦截（origin 为 null），**改成 IIFE 格式也不管用**——只要是外链文件就一律被拦。唯一解法是把所有资源内联进 HTML。
2. 内联脚本会被放进 `<head>`，DOM 未就绪就跑，导致 `canvas.parentElement === null` 报 `Cannot read properties of null (reading 'width')`。必须在 `inline.mjs` 里用 `document.readyState === 'loading'` 包一层 DOMContentLoaded 判断。
3. three.js 的 example 模块（OrbitControls / TransformControls / STLLoader 等）无需额外处理，打包后一并内联。

## 第二轮：形状库扩充 + 全套快捷键（对齐 Tinkercad）

林老板要求：快捷键全加、形状库按 Tinkercad 加满（点名要螺纹）。已全部完成并实测。

**形状 8→22 种**：新增半球、圆台、圆管、屋脊、金字塔、拱形、三角柱、弯管、十字柱、阶梯柱、星形、齿轮、螺纹、螺母。
- 螺纹：螺旋扫掠自建 BufferGeometry（梯形牙型截面，标准牙高 0.6134×螺距），内置 M4–M36 粗牙规格下拉，选 M8 自动带出 1.25。螺母=六角柱+通孔。
- 齿轮：按模数算分度圆/齿顶圆/齿根圆（rPitch=m·z/2，rOuter=rPitch+m，rRoot=rPitch−1.25m），渐开线近似齿廓 ExtrudeGeometry + 中心孔。

**新增核心范式**：
- Solid/Hole 模式（H 键）：孔渲染为半透明红，编组时实体自动并集、孔逐一差集，合并为单一网格。
- 工作平面（W 键）：射线拾取模型表面，用命中点+世界法线构建新基准面，栅格随之旋转。
- Ctrl+D 增量重复：记住上次位移量，连按生成等距阵列（已存 state.lastDup）。

**鼠标手感改为 Tinkercad 式**：右键旋转 / 中键平移 / 左键留给选择（orbit.mouseButtons 映射 + contextmenu 阻止）。

**网格步长 0.1–10mm 可调**：rebuildGrid() 重建 GridHelper，方向键微调跟随当前步长，Shift+方向键 10 倍。

**验证结论**：22 种形状逐个生成 0 报错；H→Ctrl+G 挖空实测出 1495 面带孔实体；方向键 10/100mm 步进、Ctrl+D 阵列、Ctrl+A 全选、M/F/L/W 全部响应；离线 file:// 单文件下同样 0 外部请求 0 报错。

**新增踩坑（重要）**：
1. `bindVec` 里用 `o[key[0]][key[1]]` 取值是错的——`key[0]` 取到的是字符串首字母（如 'p'），`o['p']` 为 undefined。必须显式传 `(sel, prop, idx)`。
2. 属性面板动态重建条件 `existing.join() === def.dims.join()` 命中时会 early-return，导致下拉改变参数后**输入框数值不刷新**（数据变了显示没变）。修法：早退前先回填所有 input 的 value。
3. 切换选中对象时输入框的 `_dirty` 标记会残留，导致回填被跳过。attachTransform() 里统一 clearDirtyFlags()。---

## Tinkercad Lite 第四轮：螺杆 + 6 项新功能（全部完成并验证）

**新增形状（形状库 22 → 25）**：螺杆 auger、螺旋叶片 flight、弹簧 helix。三者共用 `sweepHelical()` 螺旋扫掠内核（梯形牙型截面沿螺旋线放样，支持锥度函数 rAt(t) 与轴向函数 yAt(t)）。
- 螺杆参数：od 外径 / shaft 轴径 / pitch 螺距 / len 长度 / taper 锥度%。锥度方向：`rAt: t => rOuter*(1 - taper*(1-t))`，即底部最粗向上收缩（第一版写成 t*taper 导致方向反了）。
- 实测：默认 106×159×106mm；taper=40% 后 103.8×159×104.9mm，变径生效。
- `mergeGeometriesSafe()`：自建 BufferGeometry 无 uv 属性，与 CylinderGeometry 混合合并会失败。必须统一对齐属性集（有 uv 的补零 uv，丢弃 position/normal/uv 之外的属性）。

**D 键吸附工作平面**：选中主体按 D，沿当前工作平面法线按包围盒 8 角点最低点补偿下落。实测 Y=120 → 79.5（=螺杆半高，正好落地）。

**文字工具**：canvas 光栅化 → 轮廓提取 → 挤出。参数 size（字高）/ h（厚度），支持中英文。
- **踩坑1（关键）**：不要用 Moore 邻域回溯提轮廓。起始来向判定在圆弧笔画（「8」「O」「0」「S」）上必然失败，只走出 3 个点就被丢弃，文字悄悄回退成 size×size 方块（症状：尺寸正好等于 size×size）。
- **正确解法：边界边图法**。扫描每个前景像素与背景相邻的 4 条边，记为有向线段（沿前景顺时针），再把首尾相接串成闭环。无启发式、无起始方向猜测；外轮廓与孔洞自然分离（孔洞是反向绕行的独立环，靠有向面积符号 area>0 为外轮廓、area<0 为孔洞）。归属判定用「孔洞所有角点是否落在实体包围盒内」。
- 实测 R8 / A8 / 螺丝M8 全部正确，A/B/O/8 内孔镂空正常，中文笔画完整。

**手绘轮廓（S）**：覆盖 canvas 采集 pointer 轨迹 → 转 mm 坐标 → 管状挤出。多笔支持，Esc 取消。覆盖层 z-index 必须低于视图立方体（手绘层设为 4，viewcube 提到 30）。

**SVG 导入**：DOMParser 解析 `<path d>`，支持 M/L/H/V/C/Q/Z + 相对命令 + 贝塞尔插值，归一化 40mm 见方挤出 6mm。
- **踩坑2**：(a) `M` 分支只更新当前点却没 push 进 pts，末尾 pushSub() 时点数只有 2 < 3 被丢弃 → 任何 SVG 都报「解析失败」。(b) `Z` 是无参数命令，不能按「字符串 token 只更新 cmd 然后 continue」的写法处理，否则永远进不到 `case 'Z'` —— 需用 NO_ARG 集合在字符串分支立即执行。

**视图立方体**：CSS 3D（preserve-3d），点面切视角、拖拽转视角、⟲ 复位。背对面加 .dim + pointerEvents:none。
- **踩坑3（两个独立 bug）**：(a) `pointerdown` 立即置 vcDragging=true 而 `pointerup` 用 setTimeout 复位 —— click 早于 setTimeout 执行，标志仍为 true，点击被误判为拖拽吞掉。改用「按下点与松开点位移 > 4px」判定，不依赖异步复位。(b) pointer capture 会改写 e.target，导致 `e.target.closest('[data-vc]')` 拿错元素 —— 改用 `document.elementFromPoint(e.clientX, e.clientY)` 反查。
- **踩坑4**：相机正俯视时立方体完全对称，侧面投影成一条线点不到。给两个轴都保留 22° 最小倾角（keepTilt 函数），保证任何视角下六面都有可点面积。

**离线单文件终验（dist/index.html 1.35MB）**：以 file:// 打开 + Playwright route 拦截阻断一切非 file/data/blob 请求。结果：25/25 形状全通过、螺杆变径生效、D 键吸附正确、文字/SVG/手绘全部成功、STL 导出 284KB、外部请求 0、运行报错 0。

**环境坑**：Git Bash 的 `rm` 在本机会被拦截（SIGTERM），清理临时文件要用 `node fs.unlinkSync`。

### 本轮挖出的 5 个真 bug（都是"静默失效"型，很难靠读代码发现）
1. **index.html 残留旧硬编码的 27 个形状按钮 + 一个多余的 `</div>`** → `#left` 提前闭合，`#viewport`/`#right` 被挤出 `#app`，整页布局塌掉（body 高 2854px，画布跑到 y=1951）。上一轮以为清空成功，其实只删了一半。
2. **命令表是立即求值的对象字面量**：`'view-top': setView('top')` 在建表时就跑了一次，点击毫无反应 —— 这才是「俯视/正视按了没反应」的真正原因（此前用 `toDataURL().length` 做画面指纹误判为"按钮其实是好的"）。
3. **形状库按钮被两个委托监听器重复处理**：ShapePanel 的 grid 委托 + 全局 `[data-cmd]` 委托 → 点一次「手绘」先 startScribble 再被 toggle 的 finishScribble 立刻收尾（toast「没有绘制内容」）。修复：全局委托加 `if (e.target.closest('#shapeGrid')) return;`。
4. **`onAdd` 先判 `SHAPES[key]`**：`scribble`/`import-svg` 也在 SHAPES 表里（供参数面板用），导致走 `addShape` 放占位盒子，手绘/导入永远进不去。修复：先判命令。
5. **`rebuild()` 只换 geometry 不同步变换**：改 `o.scale` 后网格 `scale` 没更新 → 等比缩放看起来毫无反应。修复：补 `position/rotation/scale.set…` + `updateMatrixWorld()`。

### 教训
- `canvas.toDataURL().length` 不能当画面指纹（未开 `preserveDrawingBuffer`，指纹恒定），会误判功能失效。
- Playwright 里展开后的形状按钮会跑到视口外（y≈994），必须先 `scrollIntoView` 或直接 `dispatchEvent` 才能点到。
- 排序模式下形状库 click 直接 return，自动化测试若不先退出排序模式，后续所有形状点击都会被静默忽略。
- 暴露 `window.__tclite = { state, camera, meshes, transform, shapePanel, dimOverlay, THREE, ... }` 是做端到端回归的关键手段，保留在源码里。
